Pasos para publicar en GitHub Pages

  1. Guarda este código con el nombre exacto index.html.
  2. Inicia sesión o regístrate en github.com.
  3. Crea un nuevo repositorio haciendo clic en el botón "+" -> New repository.
  4. Nombra el repositorio (ejemplo: girasoles) y marca la opción Public. Haz clic en Create repository.
  5. En la siguiente pantalla, usa la opción uploading an existing file y sube tu archivo index.html.
  6. Haz clic en Commit changes.
  7. Ve a Settings -> Pages (en el menú izquierdo).
  8. En Branch selecciona main (o master) y guarda (Save).
  9. ¡Listo! En un par de minutos tendrás tu enlace web público listo para compartir.
